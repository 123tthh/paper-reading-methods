# 兼容与能力说明

## 两条接入路径

1. **技能发现**：本包使用带 `name` 和 `description` 的 `SKILL.md`，相对引用 `references/` 与 `assets/`。结构依据 [Agent Skills specification](https://agentskills.io/specification)。把完整技能目录放到宿主文档指定位置。
2. **显式读取**：向能读取文件或附件的 Agent 提供技能正文、方法手册、格式规范和目标论文；视觉输出另加 HTML/CSS。这条路径不要求宿主识别插件或技能元数据。

`plugin.json`、`.codex-plugin/plugin.json`、`agents/openai.yaml` 是可选宿主元数据；阅读与写作规则均在通用文本文件中。它们不是所有平台统一的安装入口。直接加载技能目录时无需读取这些配置。

## 能力与降级

| 任务 | 所需能力 | 缺失时如何处理 |
|---|---|---|
| 方法阅读、文字解释 | 读取 Markdown/附件 | 用户按顺序粘贴所需内容 |
| 精读 PDF | PDF 文本与图表读取 | 明确只读到的部分；需要图时请求对应材料 |
| 查证网络来源 | 检索、网页访问 | 使用用户提供的一手材料，不猜测未访问内容 |
| Markdown 笔记 | 文本生成 | 保留结构，不承诺固定颜色和尺寸 |
| HTML 彩色笔记 | 文件生成、浏览器预览 | 能生成但不能预览时明确尚未视觉核验 |
| 数学公式 | 原生公式、MathML 或其他渲染器 | 保留准确 LaTeX，标明仍需渲染，不能当作视觉交付已完成 |
| 云端笔记编辑 | 当前平台可用的编辑工具及用户授权 | 先提供本地内容；外部保存需实际读回确认 |

## 版本差异

Claude Code 的本地项目技能目录与调用方式见 [官方文档](https://code.claude.com/docs/en/skills)。云端会话、组织策略和产品版本可能改变加载方式。其他 Agent 也应查阅对应官方文档，而不是猜测隐藏目录。

本版本做过结构和引用检查，保留了原有 HTML/CSS 模板；没有逐一实测 Claude Code、Cursor、Gemini CLI 或其他宿主的完整精读流程。报告结果时区分“格式符合约定”“已加载技能”与“实际任务验证通过”。
