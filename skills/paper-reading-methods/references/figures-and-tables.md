# 原图与原表：提取、插入、讲解、核验

完整精读按本流程执行。图表来自用户指定的目标论文及其已核实官方材料，不能拿同名论文、其他版本、示意图或搜索缩略图冒充原图。仅有摘要或访问受限时明确范围。

## 1. 列出证据清单

通读正文图表标题和引用，按研究问题选取总体架构、核心机制、主要结果、关键消融与支撑结论的泛化/失败案例；有必要时补附录证据。记录所有笔记中引用的原文图表，避免正文声称“见图”却没有图。清单可放工作记录，不必在成稿重复：

| 原编号与类型 | 版本、来源及页码 | 支撑的主张 / 笔记小节 | 素材状态 | 插入、解读与核验状态 |
|---|---|---|---|---|
| 〈真实 Figure / Table 编号〉 | 〈链接，PDF 页序；印刷页码如不同另记〉 | 〈对应机制或实验〉 | 〈已提取 / 无法访问 / 不适用〉 | 〈未插入 / 已插入 / 已解读并核验〉 |

每项必须有明确状态。论文没有表格不需要制造“原表”；未覆盖的关键图表列明原因，不能用笼统的“已配图”结束检查。

## 2. 从原文提取并确认内容

- 优先论文 PDF 或作者官方项目提供的同版本高清素材。可提取原始图片，或把 PDF 页渲染后裁剪图/表区域；复杂矢量图可用高清页面裁剪，不能只抽取其中一个嵌入位图就当作完整图。
- 实际查看提取结果，对照原页确认图号、子图标签、箭头、图例、坐标轴、单位和必要脚注没有被截掉。正文宽度下必须可读；密集多面板可保留总览并分面板放大，清楚标为原图局部。
- 原表可插入截图，或忠实转录为原生可编辑表格。转录必须逐单元格比对原文，保留行列标题、方法名称、单位、指标方向、均值/误差、加粗含义及必要脚注；OCR 结果不是已核实数值。
- 需要节选、拆表或重排时注明“据原文 Table … 节选/转录/重排”，说明范围，保留关键比较对象和条件。原创归纳表另标“整理”，不冒充原文表格。
- 不用生成式图片重造论文图表，不猜测模糊数值；无法辨认时取得更清晰材料或标为未核实。

## 3. 实际插入目标载体

| 载体 | 可验收的插入方式 |
|---|---|
| 飞书等富文本 | 上传/插入图片形成实际图片块；原表用图片块或原生文档表格。只上传附件、粘贴文件路径或贴来源链接不算插入。保存后重新打开/读回相应区段，确认已加载。 |
| HTML | 使用指向真实素材的 `img`，或可核验的内嵌图片；图表放入 `figure` 配图注，可编辑表用 `table` 配标题。交付时打包所需素材，打开最终路径检查，不留失效的临时链接。 |
| Markdown | 使用实际可访问的图片引用，随文交付相对路径素材或宿主支持的有效地址；原表可用忠实转录表格。检查目标阅读器是否显示图片，不能以纯文字链接代替。 |
| Word / PDF | 将图片嵌入文档，表格使用图片或可编辑表格；渲染成页后检查分页、清晰度、脚注和截断。 |

原图保持比例，最大宽度不超过正文；可编辑表格依格式规范与正文左右对齐。原表截图裁掉多余页边空白后，让表格区域铺满正文宽度并保持比例；不拉伸变形，低清素材应换高清来源。图片内原有数学符号保持原样，新增图注和讲解中的变量仍按 LaTeX 规范排版。

## 4. 图表之后直接讲解

每张图表按“怎么看 → 看到什么 → 能说明什么 → 不能说明什么”组织，不照抄图注。

- **架构/机制图**：先给读图顺序，解释主要模块、输入输出、箭头承载的信息与子图关系；依据正文区分训练和推理、数据流和梯度，不凭箭头颜色猜测语义。回到设计动机说明为何这样连接。
- **曲线/结果图**：定义横纵轴、单位、图例、基线、实验条件和误差表示；指出已核实的趋势或对照。只有曲线可见时不给出虚假精确数值，视觉估计必须明确标注。
- **定性/失败图**：解释各列、帧序与比较对象，指出可观察差异；个案展示不能直接推成总体成功率。
- **原表**：解释行列、指标方向、单位与统计口径；挑出关键行列进行同条件比较，引用已核实数值，再说明对应的主张和限制。区分百分比、百分点与相对变化；计算得到的增幅另标“据原值计算”。

## 5. 交付验收

- 清单中的关键原图和原表均已实际显示；每项都有邻近解读、真实编号、来源链接与页码。
- 图片清楚、无缺失面板或截断，表格数值与原文相符；没有把整理表当作论文原表。
- 模板中的插图/插表占位已替换；“图见原文”、裸链接、图注与上传成功提示都不能替代成稿中的可见图表。
- 最终文件可打开，依赖素材已随附；云端文档已保存且重开可见。任何未完成项如实列出，不宣称全部完成。
